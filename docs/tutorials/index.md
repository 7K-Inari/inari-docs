# Tutorials

Step-by-step, hands-on walkthroughs for common Inari workflows. Each takes 15–45 minutes on a running platform.

| Tutorial | You'll do | Audience |
|---|---|---|
| [Register a cluster](register-a-cluster.md) | Connect a Kubernetes cluster and watch its capabilities stream in | Platform engineer |
| [Your first deploy](first-deploy.md) | Deploy a curated catalog package and watch its health | Developer |
| [Write your first extension](first-extension.md) | Scaffold, build, and install a backend + UI extension | Extension author |
| [Vend a Tenant Zone](vend-a-tenant-zone.md) | Create a new AWS account + tenant cluster from the console | Platform engineer |

Prerequisites per tutorial are listed at the top of each page. For reference material, see the [User Guide](../user-guide/index.md), [Operator Guide](../operator-guide/index.md), and [Extension Authors](../extension-authors/index.md) sections.
